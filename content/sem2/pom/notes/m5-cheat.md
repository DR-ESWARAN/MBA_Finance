**POM MODULE 5 — CHEAT SHEET**

**Quality Assurance & Control — 1-Page Rapid Revision**

*Source: Module 5 Ebook + Study Guide + LMS Quick Notes only (Module 5
"Study Notes" PDF is FM material)*

**QC —** Working to a **set, achievable standard with a ready market** =
preventing change (**control**); raising it = **breakthrough**. SQC =
better quality at lower cost. Quality of **design** (Ambassador vs
Maruti) vs **performance** (hitting target).

**INSPECTION —** **Important tool to achieve quality concept**; function
of QC; does not show **why** defects occur. 5 objectives; 9 purposes
(lots, pieces, process change, spec limits, rate product, rate
inspectors, instrument precision, design info, process capability).

| **Type**        | **Key**                                       |
|-----------------|-----------------------------------------------|
| Floor           | Patrolling inspectors at machine              |
| Centralised     | Central lab, AC room                          |
| Combined        | Floor + central                               |
| **Functional**  | **Main function only**; = assembly inspection |
| First piece     | First of shift/lot; automatic machines        |
| **Pilot piece** | **Right after new design/product**            |
| Final           | After completion; electroplating              |

**100% vs SAMPLING —** 100%: costly, no sampling error, fatigue errors;
jet engines, medical equipment. Sampling: cheap, quick, estimable error,
destructive tests; bulbs.

**SPC —** **Statistical Process Control**; output vs design;
**prevention not detection**. Via control charts for **variables**
(X-bar, R, σ) or **attributes** (p, np, c, u). Centre line, **UCL/LCL =
control limits**, CLT.

**QUALITY CIRCLES —** Japan **1960s**; participative; Juran: one
department, volunteer, weekly, company time; **members pick problems,
get training**.

**ACCEPTANCE SAMPLING —** Accept/reject a lot from a sample. n = 50, c =
3 (≤3 accept). Binomial (large lot) vs hypergeometric. **Producer's risk
α = Type I** (good rejected); **consumer's risk β = Type II** (bad
accepted). OC curve: AQL → 1 − α; LTPD → β; between = indifferent zone.
Does not guarantee quality.

**QN ONLY —** Cost of quality: **prevention · appraisal · failure**
(internal, external). **ISO 9000** = quality mgmt (process approach,
risk-based thinking); ISO 14000 = environment. **TQC** =
organisation-wide. **KAIZEN** = small steps; Gemba. Six Sigma = DMAIC.

> **TRAPS:** *LCL ≠ confidence limit (False) · circles 1970s (False) ·
> QC (not QA) = set achievable standard · inspection = tool for quality
> concept · KAIZEN not revolutionary · ISO 9000 not environmental ·
> acceptance sampling ≠ guarantee.*
