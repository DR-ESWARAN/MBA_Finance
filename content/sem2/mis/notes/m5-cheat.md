**MIS MODULE 5 — CHEAT SHEET**

**The Wireless Revolution — 1-Page Rapid Revision**

*Source: Module 5 Ebook + LMS Study Notes only*

**VALUE —** **Wireless communication** = stay in touch with customers,
suppliers, employees · productivity · save wiring · new products
(OnStar, Starbucks). SN: cost, mobility, engagement.

**LINKS —** Point-to-point = backhaul (spotlight) · point-to-multipoint
= WMAN, share the same **hub** · **access point** = WLAN (bulb).

**WiMAX —** **Worldwide Interoperability for Microwave Access** · IEEE
802.16 · MAN · 50 km fixed, 5-15 km mobile · Wi-Fi 30-100 m ·
interference **lessened** · last mile · OFDM, point-to-multipoint (SN).

**EVDO —** Data via **radio signals** · 3G · CDMA2000/3GPP2 · Qualcomm ·
packet based · 2.4 Mbps · rival W-CDMA.

**CDMA —** Maths lets **many devices transmit at once on the same
frequency**; unique signature each.

**M-COMMERCE —** Buying/selling via **wireless handheld devices** (not
agents) · WAP · ubiquity, immediacy, localization, instant connectivity,
simple authentication.

| **SN item**       | **Answer**                     |
|-------------------|--------------------------------|
| Retail m-commerce | **Amazon** (Walmart)           |
| NFC wallet        | **Apple Pay**                  |
| Security          | **Biometric**, encryption, MFA |
| Cloud CRM         | Remote access anywhere         |
| Mobile CRM        | Real-time updates              |

**CRM (Ebook) —** Two-way exchanges · CRM **data** → privacy and
security · SFA, eCRM, PRM · 4 principles: target (innovators, talkers),
match, acquire, develop · SaaS CRM lacks customisation.

**SCM —** Strategic/tactical/operational · SCOR · reverse logistics. SN:
**RFID**, GPS, **reduced lead times**, dynamic routing, route
optimisation, **JIT**, real-time data sharing.

**HEALTH —** Largest service industry · portal · real-time monitoring ·
**telemedicine = remote consultations** · wearables (smartwatch, sleep
tracking).

> **TRAPS:** *WiMAX interference increased → False · m-commerce through
> agent → False · CDMA same frequency → True · Wi-Max ≠ Wi-Fi ·
> m-commerce not only retail.*
