Managerial Economics · Notes

🫀 Analogy: Sunk cost = money already spent on cath lab construction — irrelevant for the current decision to expand. Opportunity cost = income lost from not doing private practice while in salaried post.

2. Short-Run Cost Curves

Key principle: In SR, fixed factors cannot be changed; only variable factors can.

Curve Behaviour Why
AFC (Average Fixed Cost) Falls continuously, asymptotic to X-axis TC fixed ÷ more units = less per unit; rectangular hyperbola
AVC (Average Variable Cost) Falls first, then rises — U-shaped Variable inputs more efficient near optimal output; overcrowding after
ATC (Average Total Cost) Falls first, then rises — U-shaped, turns LATER than AVC ATC = AFC + AVC; AFC still falling offsets AVC rise for a while
MC (Marginal Cost) U-shaped; cuts AVC and ATC at their minimum points MC < AC pulls AC down; MC > AC pulls AC up; equal at minimum

ATC–AVC–AFC relationships:

  • Both AFC and AVC fall → ATC falls
  • AFC falls, AVC rises:
    • Drop in AFC > rise in AVC → ATC still falls
    • Drop in AFC = rise in AVC → ATC constant
    • Drop in AFC < rise in AVC → ATC rises

Key exam point: Minimum ATC (least cost-output level = optimum output) occurs at higher output than minimum AVC.

3. Long-Run Cost Output Relationship

  • In LR, all costs are variable — firm can change plant size
  • LRAC curve = "envelope curve" — tangent to all short-run ATC curves
  • Each point on LRAC = lowest cost of producing that output given optimal plant size
  • Shape: U-shaped (due to economies then diseconomies of scale)
  • Once a planned plant is installed, that LR cost becomes the new SR cost

4. Economies of Scale

Definition: Cost reductions as production volume increases.

Internal Economies (5 types)

Type How
Technical Efficient machinery; learning curve; mfg costs fall 70–90% on doubling output
Monopsony Bulk buying power → lower input prices (e.g., Walmart's "everyday low prices")
Managerial Can afford specialists; expert sales executives, HR managers
Financial IPO access, higher credit ratings → cheaper capital, lower bond interest
Network Online: near-zero cost per additional user → pure profit (e.g., eBay)

External Economies

  • Government tax concessions to large employers
  • Roads built by cities to support large developers
  • Joint research with universities
  • Geographic clusters (small firms can cluster — art districts)

Diseconomies of Scale

  • Slower decision-making; less flexibility
  • Miscommunication in global operations
  • Culture clashes from acquisitions

5. Cost Control

Definition: Regulation by executive action to keep costs within pre-set standards. Preventive function. Emphasis on past & present.

5 Steps: Planning → Communication → Motivation → Appraisal → Decision-making

Tools of Cost Control

A. Budgetary Control

  • Uses budgets (anticipated financial plan for a period) to plan and control operations
  • Compare actual vs budgeted → identify deviations → corrective action
  • Types of Budgets:
    • Master Budget (summary of all budgets)
    • Functional (production, sales, HR, marketing, R&D)
    • Capital vs Revenue Budget
    • Fixed Budget (specific output level) vs Flexible Budget (adapts to output changes)
    • Performance Budget (links inputs to outputs/results)
    • Zero-Base Budget (ZBB) — developed by Texas Instruments (1971); every manager justifies budget from zero; eliminates wasteful activities

B. Standard Costing

  • Pre-determined cost for what product SHOULD cost under efficient conditions
  • Compare actual vs standard → variance → corrective action
  • Types of Standards: Ideal (max efficiency), Target (attainable), Basic (historical), Currently Attainable (practical)

Variance Analysis — 4 Kinds

Variance Sub-types
Material Cost Price variance, Usage variance, Mix variance, Yield variance
Labour Cost Wage rate variance, Efficiency variance
Sales Mix, Quantity, Volume, Price variance
Overhead Expenditure variance, Efficiency variance

6. Cost Reduction

Definition: Real and permanent reduction in unit cost without impairing suitability for intended use. Corrective function. Future-oriented.

Two paths: ① Reduce expenses at same output ② Increase output with same expenditure

12 Cost Reduction Techniques

  1. Organisation & Methods (O&M) — systematic activity analysis, process design
  2. Work Study — optimise use of plant, human effort; set time standards
  3. Materials Handling — efficient flow and movement of materials
  4. Automation — replaces manual work (measurement, control, data processing)
  5. Value Analysis — eliminate cost that doesn't add to function/quality
  6. Variety Reduction — standardise components; 4 stages: schedule → analyse → identify common → redesign
  7. Production Control — planning, programming, scheduling, control
  8. Design — durability, safety, simplicity, easy maintenance built into design
  9. Materials Control — buying → receipt → storage → handling → dispatch
  10. Quality Control — no defective output; right balance between rejection and over-quality
  11. Terotechnology — lifecycle cost management of physical assets
  12. Cost-Benefit Analysis (C/B) — if C/B < 1, benefit > cost → proceed

7. Cost Estimation

Definition: Pre-determining cost of a product/job for budgeting, pricing, performance measurement.

Short-Run Cost Estimation

  • Uses time-series data + regression analysis
  • Common finding: linear cost function fits SR data well
  • Problems: accounting periods ≠ economic SR; historical cost ≠ opportunity cost; inflation adjustments needed

Long-Run Cost Estimation — 4 Methods

Method Basis Key Point Limitation
Engineering Physical input estimates × current prices Uses expert/technical opinion Ignores selling & admin costs; uses current (not future) tech
Survivor (Stigler) Firms classified by size; efficient ones gain market share over time U-shaped LRAC with flat middle range (steel industry) Assumes same objectives, same environment — unrealistic
Statistical (Econometric) Historical cost & output data + regression Linear → constant MC; Quadratic → U-shaped AVC; Cubic → U-shaped AC & MC Accounting data ≠ opportunity costs; expensive
Cross-Section Compare firms of different sizes at one point in time LAC tends to be L-shaped (economies at low output, then levels off) Different accounting methods; different factor prices

MES (Minimum Efficient Scale): Smallest output where LAC is at minimum — firms below MES are at competitive disadvantage.

8. Production Function

Definition: Functional relationship between output (Q) and inputs (factors of production).

Basic formula: Q = f(L, C, N)

  • Q = Output, L = Labour, C = Capital, N = Land

3 Features:

  1. Substitutability — one factor can substitute another (law of variable proportions)
  2. Complementarity — factors work together; zero of one → zero output (returns to scale)
  3. Specificity — factors specific to particular products

Production Functions — 4 Types

Function Formula Returns Key Property
Linear Homogeneous nQ = f(nL, nK) Constant (n-fold increase in all inputs → n-fold output) Fixed optimum factor proportions
Cobb-Douglas Q = AL^α K^β α+β>1: Increasing; =1: Constant; <1: Decreasing Log-linear: log Q = log A + α log L + β log K
CES Q = A[αC^(-θ) + (1-α)L^(-θ)]^(-1/θ) All types covered Constant (not necessarily unitary) elasticity of substitution
VES V/L = a + b log W + c log K/L Variable σ = b/(1-c)(1 + WL/rK) — variable elasticity

Cobb-Douglas key properties:

  • α = labour's share and output elasticity w.r.t. labour
  • β = capital's share and output elasticity w.r.t. capital
  • If one input = 0, output = 0
  • Expansion path is linear through origin
  • Most widely used in econometrics

9. Indifference Curves

  • Graph showing combinations of two goods that give equal satisfaction (consumer is indifferent)
  • Convex to origin (MRS = Marginal Rate of Substitution)
  • No two indifference curves intersect
  • Higher indifference curve = higher satisfaction (further from origin)
  • Optimal consumption = point where indifference curve is tangent to budget constraint
  • MRS = rate at which consumer willingly gives up one good for another
