📉 Short-Run Cost Curves EXAM FAVOURITE
AFC
Falls continuously
Rectangular hyperbola
Fixed TC ÷ more units
AVC
U-shaped; turns first
Efficiency → overcrowding
ATC
U-shaped; turns LATER
ATC = AFC + AVC
AFC fall offsets AVC rise
MC
U-shaped
Cuts AVC & ATC at their MINIMUM
Key Rule
MC < AC → pulls AC DOWN  |  MC > AC → pulls AC UP  |  MC = AC → minimum point
📈 Long-Run Costs & Economies of Scale LRAC
  • In LR, ALL costs are variable — firm can resize plant
  • LRAC = envelope curve — tangential to all SR-ATC curves
  • Theoretical shape: U-shaped | Empirical: L-shaped

🎯 Cost Control Tools PREVENTIVE
Budgetary Control
  • Budget = anticipated plan in numerical terms for a period
  • Compare actual vs budget → identify deviations → correct
  • Fixed Budget — specific output level
  • Flexible Budget — adapts to output changes
  • ZBB (Zero-Base Budget) — Texas Instruments 1971; every manager justifies from zero; eliminates wasteful activities
  • Performance Budget — links inputs to outputs (USA 1960s)
Standard Costing
  • Pre-determined cost under efficient conditions
  • Actual vs Standard → variance → corrective action
  • Standards: Ideal → Target → Currently Attainable → Basic

🏭 Production Function HIGH YIELD
Q = f(L, C, N)  |  Q = output, L = Labour, C = Capital, N = Land
3 Features: Substitutability (variable proportions) · Complementarity (returns to scale) · Specificity (factors specific to products)
FunctionFormulaReturns to ScaleKey Fact
Linear Homogeneous nQ = f(nL, nK) Constant n-fold inputs → n-fold output; fixed optimum proportions
Cobb-Douglas Q = AL^α K^β α+β>1: Increasing
α+β=1: Constant
α+β<1: Decreasing		 Log Q = log A + α log L + β log K | α = labour share; β = capital share | Most used in econometrics
CES Q = A[αC^(-θ)+(1-α)L^(-θ)]^(-1/θ) All types Constant (not necessarily unitary) elasticity of substitution; more general than C-D
VES V/L = a + b log W + c log K/L Variable σ = b/(1-c)(1+WL/rK); most general; neo-classical properties
〰️ Indifference Curves
  • Combinations of 2 goods giving equal satisfaction
  • Convex to origin — MRS = Marginal Rate of Substitution
  • No two curves intersect
  • Higher curve = higher satisfaction (further from origin)
  • Optimal consumption: tangent point of indifference curve & budget constraint
