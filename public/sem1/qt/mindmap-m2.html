2. Requisites of Good Classification 8 — MCQ

#RequisiteKey Point
1UnambiguousNo confusion or overlap in placing items
2ExhaustiveEvery item fits somewhere — no item left out
3Mutually ExclusiveEach item in ONE class only
4FlexibleAdjustable to changed situations
5StableSame principle throughout — enables time comparison
6SuitableMatches investigation objective
7HomogeneousSimilar items within same class
8RevealingBrings out patterns — not too few or too many classes
🫀 Clinical Analogy: Classifying patients into diagnostic groups — must be Exhaustive (no patient left unclassified), Mutually Exclusive (one diagnosis per patient), Revealing (groups show clinical pattern).

4. Frequency Distribution — Discrete

TypeFeature
UngroupedIndividual values + frequencies; original identity preserved
GroupedValues grouped into intervals; pattern visible; identity lost
Tally Marks Method
Each obs = one tally mark | 5th mark crosses previous 4: |||| Used to count frequencies
When to Group?

When ungrouped distribution fails to reveal any pattern, or when the number of possible values is too large.

📈

5. Frequency Distribution — Continuous KEY FORMULAS

Key Decisions
DecisionRule
No. of classesMin 5–6, Max 20
Width(L − S) / n
Mid-value(Lower + Upper) / 2
n = 1 + 3.322 × log₁₀N
Sturge's Formula — number of classes
Class Limit Methods
MethodRule
ExclusiveUpper limit = lower limit of next class
Includes: ≥ lower, < upper
e.g. 10–20 excludes 20
InclusiveIncludes: ≥ lower, ≤ upper
Gap between classes → need class boundaries
Types of Freq. Distributions
TypeDescription
Relative / %Frequencies replaced by proportions or percentages
Less than Cum.Add frequencies lowest → highest
More than Cum.Add frequencies highest → lowest
Freq. DensityFreq / Class width — rate of concentration
📈 Trading Analogy: Frequency distribution of stock returns = histogram of daily P&L — tells you where returns cluster, how wide the spread is, and whether distribution is skewed.

6. Bivariate & Multivariate Distributions

TypeCharacteristicsRepresentation
Univariate1 characteristicStandard freq. table
Bivariate2 characteristics simultaneouslyContingency Table
Multivariate>2 characteristicsComplex cross-table
Example — Bivariate

100 couples classified by Age of Husband AND Age of Wife simultaneously → Contingency Table

🫀 Clinical Analogy: Bivariate = cross-tabulating patients by Age Group AND Blood Pressure Category. One variable alone tells half the story.
