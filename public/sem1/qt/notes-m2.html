Module 2 · Classification of Data

Quantitative Techniques · Notes

NotesMind map

1. Why Classification?

  • Raw collected data = complex, unorganised mass of figures → difficult to analyse
  • Classification + Tabulation = organises data into a definite, interpretable form

2. Chief Characteristics of Classification (5)

  1. Data arranged into homogeneous groups
  2. Basis = similarity of characteristics in collected data
  3. Signifies unity in diversity
  4. May be actual or notional
  5. May be based on measurable, non-measurable, or both characteristics

3. Objectives of a Good Classification (6)

  1. Present mass of data in condensed form
  2. Highlight similarity and dissimilarity
  3. Bring out relationship between variables
  4. Highlight effect of one variable by eliminating effect of others
  5. Facilitate comparison
  6. Prepare data for tabulation and analysis

4. Requisites of a Good Classification (8) — HIGH YIELD

# Requisite Meaning
1 Unambiguous No confusion in classification
2 Exhaustive Every item must fit into some class — no item left out
3 Mutually Exclusive Each item in ONE class only
4 Flexible Adjustable to changed situations
5 Stable Same classification principle throughout — enables comparison over time
6 Suitable Matches the objective of investigation
7 Homogeneous Similar items within same class
8 Revealing Must bring out essential features; not too few or too many classes

5. Types of Classification (5)

Type Basis Example
Geographical / Spatial Location / region State-wise sales data
Chronological Time of occurrence Annual national income, monthly expenditure
Conditional Conditions other than geographical/chronological —
Qualitative (Attributes) Non-measurable characteristics (attributes) Sex, marital status, colour, honesty
Quantitative (Variables) Measurable in numbers (variables) Height, income, age

Qualitative Classification — Subtypes

  • Dichotomous / Twofold — 2 categories: presence or absence of attribute (e.g., Male/Female)
  • Manifold — More than 2 categories (e.g., eye colour: black, brown, grey, blue)
  • One-way — Classified by 1 attribute
  • Two-way / Multiway — Classified by 2 or more attributes simultaneously

Quantitative Classification — Variable Types

Variable Definition Example
Discrete Takes only specific values in an interval No. of children, no. of rooms
Continuous Can take any value in an interval Income (₹1,500.25), height, age

6. Formation of Frequency Distribution

A. Discrete Frequency Distribution

  • Ungrouped — individual values + frequencies listed; identity of observations preserved
  • Grouped — observations grouped into intervals; pattern becomes visible; original identity lost
  • Tally marks method used for counting frequencies (fifth mark crosses previous four: ||||)

B. Continuous Frequency Distribution — Always Grouped

Key decisions in construction:

Decision Rule
Number of classes Min 5–6, Max 20
Sturge's Formula n = 1 + 3.322 × log₁₀N (n = no. of classes, N = no. of observations)
Width of class interval Equal width preferred; Width = (L − S) / n
Class limits Lower limit ≤ smallest obs; Upper limit ≥ largest obs

Class Limit Designation Methods

Method Rule Inclusion
Exclusive Upper limit = lower limit of next class ≥ lower, < upper (10–20 excludes 20)
Inclusive All values ≤ upper limit included ≥ lower, ≤ upper; need class boundaries

Mid Value of a class = (Lower limit + Upper limit) / 2

C. Relative / Percentage Frequency Distribution

  • Replace actual frequencies with relative frequencies (proportion) or percentages
  • Useful for comparison across datasets of different sizes

D. Cumulative Frequency Distribution

Type How Constructed
Less than Add frequencies from lowest to highest class successively
More than Add frequencies from highest to lowest class successively

E. Frequency Density

  • Frequency Density = Frequency / Width of class
  • Gives rate of concentration of observations in a class

7. Bivariate and Multivariate Frequency Distributions

Type Characteristics Representation
Univariate Classified by 1 characteristic Standard freq. table
Bivariate Classified by 2 characteristics simultaneously Contingency table
Multivariate Classified by >2 characteristics Complex cross-table

High-Yield Exam Points

  • 8 Requisites of a good classification — MCQ favourite (Exhaustive, Mutually Exclusive, Revealing)
  • 5 Types of classification — know one-liner definition of each
  • Sturge's Formula: n = 1 + 3.322 × log₁₀N — formula-based question
  • Discrete vs Continuous variable distinction
  • Exclusive vs Inclusive method — class limit designation
  • Less than vs More than cumulative frequency
  • Bivariate → Contingency table (term MCQ)
